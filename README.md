# DataDoc – AI Data Analyst Copilot

## Overview
DataDoc is an AI-powered Data Analysis Assistant that enables users to upload CSV/Excel datasets, analyze them using Natural Language, generate visualizations, and receive AI-generated business insights using Gemini, LangChain, and ChromaDB.

## Tech Stack
- Python
- Streamlit
- Pandas
- Plotly
- Gemini API
- LangChain
- ChromaDB

## Features (Planned)
- CSV/Excel Upload
- AI Chat with Data
- Automated EDA
- Interactive Charts
- AI Business Insights
- RAG-based Question Answering
- Report Generation
